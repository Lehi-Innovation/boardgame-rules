## Q115 comparison

Q115 asks: “When an ordinary non-Company Invasion fails, which region loses a tower level?” Its sole mandatory fact is: “A failed ordinary non-Company Invasion removes one tower level from the attacking region”.

Q088 already asks “what success results apply?” and requires “Defeated normal primary Invasion loses one attacker tower if possible”. Q015 asks “what happens on successful defense?” and likewise requires “Defeated normal primary Invasion loses one attacker tower if possible”. Q050 separately tests the ordinary non-Company comparison and failure on a tie.

The p32 ordinary Invasion rule and p33 Company-defense rule produce the same one-level attacker loss. Different defender categories govern how failure is reached, already covered by Q050 and Company-defense questions; Q115 asks only the common consequence. It does not test a zero-tower exception, a distinct order of operations, or another consequential difference. “If possible” in existing Q015/Q088 is not an exception newly asked by Q115.
