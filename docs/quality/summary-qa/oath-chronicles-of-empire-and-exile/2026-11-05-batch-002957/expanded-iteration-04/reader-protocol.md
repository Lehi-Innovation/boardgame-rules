# Fresh reader protocol: expanded iteration 04

Both readers receive the same instructions, differing only in identity and output path. Only the frozen summary and questions are external inputs. No source, key, scope, grade, history or other reader output is provided.

1. Receive every character of both input files in contiguous chunks of at most4,000 characters. Print exact content between BEGIN/END filename/start/end/total/SHA256 markers. At most two chunks per call; both outer and inner output caps6,000. Retry any truncated chunk. Save range receipts. A Python read without model-visible text is insufficient.
2. Answer all103 IDs once, in batches of20 plus the remaining3 if useful. Every requested clause and concrete scenario needs a direct response. Unsupported requested content must be identified; do not guess or add unrelated hypothetical complications.
3. Attach exact **complete relevant named sections**, from heading through all paragraphs/tables/steps before the next heading of equal or higher level. Include all controlling sections for a question spanning more than one procedure. A heading alone or a selected fragment is insufficient. No unrelated whole-summary dump. Extract programmatically and verify each section is an exact nonempty substring containing actual rule text.
4. For a direct rule-enumeration question the attached complete procedure is part of the operative answer; give a concise direct orientation. For concrete scenarios give the actual conclusion and attach all controlling rules. Avoid unsupported extra paraphrases or invented examples.
5. After drafting all103, do a second semantic self-check of every answer against its own complete cited sections and every clause in its question. Check actors, roles, permissions, requirements, triggers, order, timing, quantities, costs and conditions. Fix contradictions or unresolved requested parts using only the summary. Merely checking IDs/quote substrings is insufficient.
6. Save JSON with game, reader, input paths/hashes, delivery receipts, self-review metadata and answers containing id/answer/support/evidence/verbatim_passages. Own assigned-prefix draft/batch files may be assembled and reread for self-check. Do not read any other outputs. Validate exact requested ID set and all quote strings in memory before final report.

This is an extractive, tool-assisted fixed regression protocol with scenario applications. It does not claim unaided paraphrase accuracy, a controlled summary-only comparison against historical runs, or held-out performance. Semantic grades still fail material application contradictions even if attached rule text is correct.
