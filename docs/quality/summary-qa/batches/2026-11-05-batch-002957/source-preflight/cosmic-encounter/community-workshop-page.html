Description
Fully functional - 2026 - Updated for Cosmic Odyssey!

Includes scripted setup, fixed DLC, community content, useful tools, and improved performance.

This was made as a love letter to Cosmic Encounter and wanted it properly represented in Tabletop Simulator with as many features as possible. I've been actively maintaining this mod and welcome new feature ideas or possible bug fix suggestions!

Upvote if you enjoyed this setup and to show that cosmic encounter mods are still alive! Thanks to those of you that have voted!

Features:
  • Alien and Flare auto dealing and setup for all aliens and player components! Includes options for individual expansions, dealing specific complexities, and gathering alien specific pieces! Includes advanced options for dealing more and a homebrew distributer for dealing your own personalized set of aliens/flares.
  • Fixes multiple glitches. All cards are now hidden while in player hands and cards don't fall through the main table (unlike the base DLC table). Includes the missing Nightmare card and missing Demon Alien.
  • Enlarged aliens for character avatars
  • Tools for hand flipping/shuffling/grouping/counting, negotiation timer, warp counter, and card distributions.
  • Supports double powers and hidden aliens!
  • A new Cosmic Counter which is used to calculate math heavy attacks during encounters.
  • Hazard warnings are announced when the appropriate destiny is drawn. Includes variant for hazards on second encounter only! Works by drawing destiny or with the phase tracker.
  • Hidden alliances now possible with the new Alliance tool which will print out everyone's committed ships to the chat simultaneously. Includes support for foreign aid!
  • Phase tracker button to easily announce the current phase.
  • Auto discard buttons to move all face up cards on table to the appropriate pile. Ignores flares and certain cards that remain in play.
  • Throwing anything off the table will send it to the void on the side table. Used when components are removed from play.
  • Cosmodex Revised and House Rule aliens are mixed in (originals still on side table).
  • Many additional custom Rewards, Hazards, Tech and Space Stations if desired to mix in.
  • There is also Cosmic Stars as a custom variant! Each system gets its own star that can be used by any player with enough ships in that system.
  • Replaced the black tokens with their pink versions to match the player colors.
  • Significantly improves performance over the base table.

Notes:
  • For the void tile and discard function to work, physics need to be "full" (on by default).
  • Recommend avoiding the undo function during game setup. It should be fine after starting hands have been dealt and the game has started. Please send a bug report in the discussions if something breaks.
  • When sending objects to the void, tabletop will group any other object that was moved simultaneously. This is rare but check the void if a card or component goes missing.
  • TTS has many underlying bugs that cannot be fixed, but none should break the mod. Most notably are some ships turn white and some counters missed an update, both of which can be fixed by moving the pieces.
