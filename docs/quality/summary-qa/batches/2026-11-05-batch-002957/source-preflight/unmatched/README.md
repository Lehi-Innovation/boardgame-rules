# Unmatched base component source supplement

This supplement was prepared before dispatching Unmatched. It supplies the four character cards and four complete action-card sheets for the original Battle of Legends, Volume One base set.

The [Unmatched Official module](https://steamcommunity.com/sharedfiles/filedetails/?id=2132611236) lists Restoration Games and imadjinn as creators. Its June 2020 public component file includes the original four base fighters. Other fighters in the module remain outside this assignment.

[Provenance](provenance.json) records the saved creator page, public API metadata, raw BSON and decoded JSON, asset URLs, retrieval details, and hashes. Each of the eight downloaded images has the exact SHA-1 content identifier embedded in the module's UGC asset URL. The old asset host failed HTTPS certificate-name validation; the current Steam CDN served the same immutable assets with TLS verification enabled.

The character images are named `<fighter>-character.png`; action sheets are `<fighter>-action-cards.png`, six columns by five rows. Preserve these inputs read-only. The worker must inspect all source components and retain any inspection derivatives in its own assigned evidence directory.

The licensed rulebook remains the shared-rules authority. This supplement does not establish later errata or authorize importing other sets. [The queued worker prompt](../../worker-prompts/unmatched.txt) and batch manifest include these sources.
