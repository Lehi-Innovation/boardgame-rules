# Reader protocol v6

The same67 questions/key/scope and whole-answer factual threshold remain fixed. Complete same-entry operative source text is an answer, as explicitly required by the coordinator’s whole-answer standard. Lookup facts are supplied directly in those units; redundant paraphrases of names/types/amounts are avoided. Only concrete case decisions or arithmetic not already stated in the matched source require additional prose. Every requested clause, including an expressly tested global restriction, must still be supplied.

This is a process change without new rule facts, failed IDs, keys, past answers or grades. It does not waive requested facts or excuse wrong applications. The canonical source body and its independent source audit remain unchanged. Both fresh readers still receive only frozen summary/questions as data, with identical prebound generic instructions and technical next-batch continuations.
