[Unmatched] Inarrêtable Excalibur !

Publié le 11 août 2025

Nos partenaires de Restoration Games viennent d’officialiser un changement de règles concernant le personnage du Roi Arthur.

Pour comprendre ce changement, il faut prendre le temps de revenir sur la capacité d’Arthur, qui indique ceci :

« Lorsque le Roi Arthur combat, il peut BOOSTER son attaque. Jouez la carte BOOST, face cachée, avec votre carte Attaque. Si votre adversaire annule les effets de votre carte Attaque, la carte BOOST est défaussée, sans effet. »

Le changement de règle implique la carte Excalibur, une carte d’attaque de valeur 6. Auparavant, si la carte Excalibur, une fois boostée, était contrée par une Feinte, la Feinte avait pour effet de défausser la carte utilisée pour le Boost. Ce n’est plus le cas désormais, dans une modification officielle apportée par Restoration Games.

Cette règle prend donc immédiatement effet, aussi bien pour le jeu amical que pour les tournois :

« Comme Excalibur n’a aucun effet imprimé sur sa carte, ses effets ne peuvent pas être annulés. Si Arthur utilise sa capacité pour BOOSTER Excalibur, la carte utilisée pour le BOOST n’est pas défaussée si l’adversaire annule les effets sur Excalibur. »
