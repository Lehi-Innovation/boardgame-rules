# Reader protocol v5

The factual standard and all67 fixed questions/key/scope remain unchanged. This version requires full-source lookup before absence claims, the controlling source unit for every named item, and checking exception triggers before case application. It supplies no game facts or failed IDs.

Exact source spans and complete requested facts remain required. The reader no longer has to execute a large Markdown-classifier program; optional kind/header labels are separated from factual correctness, as directed by the coordinator. Root still preserves full raw entries, verifies exact source spans and lossless grader transport, and grades every actual requested fact. All prior protocols, validation findings, raw outputs and failures are retained. New readers are required for substantive failures, not optional metadata.
