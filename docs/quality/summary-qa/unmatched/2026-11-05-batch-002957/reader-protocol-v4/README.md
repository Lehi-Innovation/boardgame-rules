# Reader protocol v4

Retains the same fixed-bank whole-answer factual standard and unchanged optional mechanical validator. A generic numerical self-check asks readers to restate scenario givens, match substitutions to those givens and identify a stated rule for any change. It supplies no game facts, failed IDs, keys, prior answers or grades.

The previous full pair remains preserved and is being completely graded. A new pair is justified by a demonstrated substantive arithmetic contradiction, separately from metadata or own-revision findings. Only the summary is clarified from sources; the questions/key/scope remain fixed. All numerical and nonnumerical requested clauses still count.
