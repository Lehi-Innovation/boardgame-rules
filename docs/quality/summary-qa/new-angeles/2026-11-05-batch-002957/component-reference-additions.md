### Ordinary action reference

Each type contains five copies of each of these four printed actions. Resolve the winning card in its printed order; a card's explicit exemption is local to that card. These instructions supplement the general deal and district rules.

| Type / card | Printed procedure |
|---|---|
| Labor — Efficiency Experts | Move 1 android to a district without an android. Illness does not increase threat during this action. |
| Labor — High-Risk Investments | Choose 3 players in order: first gains 3 capital, second 2, third 1. |
| Labor — Labor Solutions | Move up to 3 androids to districts without androids, one at a time under the normal movement rule. Then place 1 orgcrime in any district. |
| Labor — Liquidation | Choose a district not in strike or outage; it produces all its resources, ignoring orgcrime. Then raise its unrest to strike. It does not exploit the district; development and supply caps still apply. |
| Media — Media Circus | Decrease unrest by 2 stages in any district. Then place 1 Human First in any district. |
| Media — 24/7 Live Feeds | Decrease unrest by 1 stage in any district or remove 1 orgcrime. |
| Media — Puff Piece | Starting with active player, clockwise, each player may draw 2 actions of one type of their choice, or 3 if they supported this offer. |
| Media — Spin Doctors | Decrease unrest by 1 stage in up to 2 districts. Then reduce supply credits by 1; if credits are already 0, add 1 threat instead. |
| Security — Arrest Orders | Place 1 prisec in any district to remove all other units in that district. |
| Security — Full Deployment | Choose another player and choose whether they draw 5 actions of a type you choose or flip their emergency faceup. |
| Security — Riot Control | Remove 1 prisec from any district to remove up to 2 enemies from the city. Then increase unrest by 1 stage in 1 district not in strike or outage. |
| Security — Scorched Earth | Place 1 outage in a district not in outage to remove all enemies there and in another district of that tier. |
| Construction — Ark Construction | Place 1 development in any district. |
| Construction — Gentrification | Remove 1 outage from any district. Then place 1 prisec there if it does not contain prisec. Each enemy there moves. |
| Construction — Budget Renovations | Remove up to 2 outages from the city. Then increase unrest by 1 stage in each district from which you removed an outage. |
| Construction — Vanity Project | Choose 1 player, who gains 2 capital or 4 if they supported this offer. Then discard 1 of that player's assets if possible. |
| Biotech — Clean Slate | Remove up to 2 illnesses from the city. Then place 1 outage in a district where you removed an illness. Illness does not increase threat during this action. |
| Biotech — Clinical Trials | Remove 1 illness from any district. Illness does not increase threat during this action. |

Use the general same-timing order, exhaustion and discard rules. The official exceptions in FAQ & Rulings remain controlling.

### Investment reference

Score only at the Score Investment step. In the resource-sector rows, **S** is that resource's actual supply then; the entire award is zero if that resource misses its own demand, even if a formula would otherwise be positive. For count rows, use the current city, not the reserve or the Root. Counts below the first listed threshold yield no listed award.

| Investment | Capital award |
|---|---|
| Banking Sector | If credits meet demand, min(6, 2 + S). |
| Energy Sector | If energy meets demand, min(7, 3 + 2S). |
| Entertainment Sector | If entertainment meets demand, min(6, 2 + S). |
| Retail Sector | If consumables meet demand, min(6, 2 + 2S). |
| Technology Sector | If tech meets demand, min(6, 3 + S). |
| Healthcare Initiative | 2 illnesses: 3; 3: 5; 4 or more: 7. |
| Laundering Scheme | 2 orgcrime: 3; 3: 5; 4 or more: 7. |
| Militarized Police | 1 prisec: 3; 2: 6; 3 or more: 8. |
| Populist Dismissal | 1 for each district in protest or strike. |
| Power Siphoning | 1 outage: 3; 2: 5; 3 or more: 7. |
| Short Sale | Count resource types whose supply is 1 or less: 1 type: 3; 2: 5; 3 or more: 7. |
| Union Agreement | 2 Human First: 3; 3: 5; 4 or more: 7. |

Source: all 12 original investment faces; RR §§18, 33; FAQ Investments.
